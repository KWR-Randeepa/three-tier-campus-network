PACKET TRACER 9.0 - THREE-LAYER HIERARCHICAL NETWORK
======================================================

This is a configuration and build pack for the topology in the supplied
reference image. It is not a native .pkt file. Build the topology in Packet
Tracer 9.0, connect the ports according to PORT_CONNECTION_MAP.txt, then
paste the matching CLI file into each switch.

DEVICE COUNT
------------
2 x Catalyst 3560-24PS (CORE1, CORE2)
4 x Catalyst 3560-24PS (DSW1-DSW4)
4 x Catalyst 2960-24TT (ASW1-ASW4)
8 x PC-PT
4 x Printer-PT

BUILD
-----
1. Place 2 core switches in the top row.
2. Place 4 distribution switches in the middle row.
3. Place 4 access switches in the bottom row.
4. Place 2 PCs and 1 printer below each access switch.
5. Rename devices using the names in the port map.
6. Make all switch-to-switch links shown in the port map.
7. Connect each access switch Fa0/1 to a PC, Fa0/2 to another PC,
   and Fa0/3 to a printer.
8. Paste each switch's matching file from device_configs.

CABLES
------
For switch-to-switch copper links, use Copper Cross-Over or the Packet
Tracer automatic connection tool.
For switch-to-PC/printer links, use Copper Straight-Through.

CONFIGURATION
-------------
Open a switch, select CLI, answer "no" to the initial configuration dialog
if it appears, press Enter, and paste the matching configuration.

Configure in this order:
CORE1, CORE2, DSW1, DSW2, DSW3, DSW4, ASW1, ASW2, ASW3, ASW4.

END DEVICES
-----------
Set all PCs to DHCP:
PC > Desktop > IP Configuration > DHCP

Set printer static addresses:
Printer > Config > FastEthernet0 (or Desktop/IP Configuration if shown)

Printer 1: IP 192.168.30.101, mask 255.255.255.0,

VERIFY
------
On switches:
show vlan brief
show interfaces trunk
show spanning-tree
show standby brief
show ip interface brief

On CORE1:
show ip dhcp binding

On PCs:
ipconfig
ping 192.168.10.1
ping 192.168.30.101

EXPECTED BEHAVIOUR
------------------
HSRP provides redundant default gateways:
VLAN 10 gateway 192.168.10.1 (CORE1 preferred)
VLAN 30 gateway 192.168.30.1 (CORE2 preferred)
VLAN 99 gateway 192.168.99.1 (CORE1 preferred)

Rapid-PVST manages redundant Layer 2 paths. Some redundant ports may
display amber/orange while spanning tree blocks them to prevent loops.
This is normal.

The DHCP pool is configured on CORE1 only. HSRP gateway redundancy does
not make DHCP service redundant. Existing clients can retain leases if
CORE1 goes down, but new DHCP leases will require CORE1 to be available.

The supplied reference image does not label switch models, interface
numbers, VLANs or IP addresses. This pack uses a consistent Packet Tracer
9.0 implementation of the same visible three-tier layout.
